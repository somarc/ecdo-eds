Instrument — where measurement lives

ECDO is a unifying hypothesis stack. It is not a substitute for instruments. This page draws the boundary Cunningham’s own modeling essay implies: empirical touchpoints and multi-lane co-display first; black-box prophecy never as a front door.

Two surfaces, one discipline

This site (ECDO Lab) owns dense theory language: State 1 / State 2, indigo / Tau, four pillars, monument methodology, source provenance. It is allowed to be verbose because hypotheses need room to be stated fully enough to be attacked.

Wobblescope (local sister project under marc_projects/ecdo) owns measured and modeled Earth-system lanes on one scrubbable timeline: IERS polar motion and LOD, geomagnetic indices, ocean SST, quakes, volcanoes, space weather, AAM, and more—with epistemic badges so “measured” never pretends to be “exploratory dual-state proof.”

Wobblescope’s public product posture is a LIVE lobby—arrive in now, see recent events—not a dual-state catastrophe UI. That is intentional. ECDO hypothesis experiences, if added later, must be opt-in, labeled exploratory, and never the anonymous default.

What to watch in the instrument if you care about ECDO signals

  • Ocean SST / ENSO lanes—and, when available, deeper ocean heat products—for ocean-first and abyssal questions (see Signals).
  • Geomagnetic indices and magnetic pole markers for field context—not as a Tau clock.
  • IERS polhode and LOD with AAM coupling as established rotation physics; refuse to relabel meters as 104°.
  • Seismicity organization only as raw events unless a research layer explicitly tests Euler-axis hypotheses.

What never belongs on the LIVE lobby

  • Countdown to Tau
  • Unlabeled State 1→2 flip as “news”
  • Monument azimuth scores mixed into earthquake feeds without epistemic quarantine
  • Single-score “ECDO danger” composites
